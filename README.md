# Real Time DFT -Molecule visualization (with precomputed orbitals )
This is a workflow to visualize atomistic movements that are otherwise not obtainable by traditional DFT methods(for CO2 and XY style molecules) .  From the PES of the system generated by the DFT. A scan of scf convergence across the linear or genralized coordinate is taken to account for better visualization. Finally the orbitals are precomputed and loaded in taichi to visualize.

This workflow is written to account for mainly two types of molecules. Triatomic and Diatomic . The diatomic version ( HCl ) uses Numerov's algorithm to solve for nuclei positions meanwhile triatomic case ( CO2 ) , the a more sophisticated finite difference and diagonalization method to directly determine the eigenvalues without any exponential blowup for complex cases. Also the triatomic case uses a generalized coordinate to account for the triatomic system of CO2 . The vibrational modes of CO2 are also accounted for here as 3 types of vibrations need distinct types of treatment. 

The workflow of visualization is divided into 3 steps ,and an optional plotting of vibrational modes to see whether the visualization will be worth the computation or not. 

# Requirements


# WORKFLOW Summary
Step1: Convergence sweep of DFT (scf) across the selected mode ( not needed for the linear diatomic PES case)

Step2: Optional Vibrational Modes curve plotting ( usage of step's convergence  output csv to generate plot )

Step3: Precompute orbittals for the next visualizer to take inputs and load files wothout running prohibitive real time DFT calculations

Step4: Load the precomputed orbitals csv and the PES to recompute electron denisty shift and nuclei shift in real time and render it on a GPU.

For an example, this refernce picture ( a screenshot of the running animation) using CO2 was achieved by running these commands consecutively :: 

Step 1: ( PES and scf sweep )

```bash
# Run DFT PES calculation after navigating to the CO2 directory of this repo
python co2_dft_pes_1.py --mode bend --basis def2-svp --xc b3lyp  --qmin -0.8 --qmax 0.8 --points 33 --output pes_co2_bend.csv

```

Step2: ( Optional Vibrational mode plotting ) 

```bash
# Run plotting to see whether the modes are within range
python co2_vibrational_levels.py --input pes_co2_bend3.csv --mu-amu 12.887753 --nlevels 6 --plot-png levels_bend_wb97x.png
```

Step3: ( Precompute orbitals for rendering later ) 

```bash
# Precompute orbitals cache for loading and rendering later
 python co2_precompute_orbitals3.py --pes-csv pes_co2_bend3.csv
```

Step4 : ( Final Taichi GGUI visualization )

```bash
# Final visualization using rev2 (recommended for qualitative understanding) 
python co2_taichi_vibration_4_rev2.py --orbitals orbitals_co2_bend.npz --pes pes_co2_bend3.csv
```
